## Sobre o projeto

Este repositório foi desenvolvido como continuidade das ADOs anteriores, com o objetivo de aplicar uma identidade visual própria e coerente em uma interface web responsiva.

O projeto simula uma gravadora fictícia chamada EchoWave Music, substituindo os elementos genéricos do Relume Kit por uma proposta visual personalizada, com paleta de cores, tipografia, imagens e conteúdos alinhados ao segmento musical.

---

## Objetivos

* Aplicar identidade visual em uma interface web
* Desenvolver uma proposta visual coerente para um negócio fictício
* Utilizar variáveis CSS para padronização da paleta de cores
* Trabalhar tipografia personalizada com Google Fonts
* Adaptar conteúdos e imagens ao contexto da marca
* Reforçar conceitos de responsividade e organização CSS
* Manter a estrutura semântica e responsiva das ADOs anteriores

---

## Sobre a EchoWave Music

A EchoWave Music é uma gravadora fictícia de autoria minha, focada em artistas independentes, grupos musicais e produções criativas voltadas ao cenário pop contemporâneo.

A proposta visual da marca busca transmitir modernidade, identidade artística e presença digital, utilizando uma estética minimalista.

---

## Identidade visual

O projeto utiliza uma paleta de cores personalizada definida através de variáveis CSS no `:root`, garantindo consistência visual em toda a interface.

Também foi aplicada tipografia personalizada via Google Fonts para fortalecer a identidade da marca e melhorar a experiência visual do usuário.
